# 🤖 Rule-Based Chatbot

A simple Rule-Based Chatbot developed using Python as part of the **CodeOrbit AI Internship**.

The chatbot responds to predefined user inputs using conditional statements and keyword matching.

---

## 📌 Features

- Greeting Messages
- AI Information
- Python Information
- Current Date & Time
- Simple Calculator
- Random Jokes
- Help Menu
- Exit Command
- Rule-Based Responses

---

## 🛠️ Technologies Used

- Python 3
- Random Module
- Datetime Module

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/TejaswhiKY/Rule-Based-Chatbot.git
```

Go to the project folder

```bash
cd Rule-Based-Chatbot
```

Run the chatbot

```bash
python chatbot.py
```
